One-Line Roast: The Gadget You Use Every Day. A Node program that writes a single 192-character roast of the new touchscreen MacBook Pro to /output/entry.txt: Steve Jobs warned a touchscreen laptop would make your arm fall off; fifteen years later Apple shipped it anyway, fingerprints, ProMotion smudges, $19 polishing cloth and all.

## Run it

```sh
node main.ts
```
